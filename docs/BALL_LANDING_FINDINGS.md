# 球落点(frame24)调查结论汇总

> 目标：找出 frame24 落点误差的真正来源，定主攻方向。
> 方法：① 7 个训练实验的指标表横比；② `tools/verify_physics_extrapolation.py` 在
> exp003 / exp004 上做 frame24 误差分解(pos15 起点 × 选球来源 × 外推公式)。
> 结论一句话：**frame24 的病根是 pos15(球定位)，不是选球、不是外推；LSeg 是当前把 pos15 压下去的关键，不该弃。**

## 2. 六大发现

### 发现 1：frame24 ≈ pos15 起点误差
外推 + 速度只贡献很小的额外误差：
- exp004：pos15 0.089 → frame24 0.101（+0.012）
- exp003：pos15 0.035 → frame24 0.062（+0.027）

→ **pos15(球在 frame15 的定位)是 frame24 的绝对主导。**

### 发现 2：选球不是瓶颈
pred(预测语义选球) ≈ gt(GT选球)，甚至 pred 略好：
- exp004：pos15 pred 0.0897 vs gt 0.0892；frame24 pred 0.1072 vs gt 0.1089
- exp003：pos15 pred 0.0358 vs gt 0.0346

→ **语义选球没问题。ball token 的"绕开脆弱选球"卖点不成立。**

### 发现 3：外推(a/j)不是瓶颈
`phys`(完美重力 g、j=0) ≈ `free`(网络 a/j)，只差 ~7%。`linear`(去重力)崩到 0.44 ≈ `0.5·g·dt²` 的重力下落量，证明脚本正确、重力项必须有（但它只是对照，不是候选）。

→ **物理外推(方案 A)、改动 B(训练固化 a/j)对 frame24 收益都很小，搁置。**

### 发现 4：逐像素指标 ≠ pos15（口径陷阱，被误导多次）
- exp004 逐像素 `ball_depth` 好一倍(0.025 vs 0.055)，pos15 却**差 2.6 倍**(0.089 vs 0.035)。
- 逐像素 `ms3_acc` median≈0.3，但球区域取 median 后 a≈g（噪声消掉），所以换 a 没用。

→ **决定 pos15 的是"球整体几何系统一致性"，不是逐像素随机精度。别再用逐像素指标推 frame24。**

### 发现 5：LSeg 大幅改善 pos15/落点（策略反转）
exp003(LSeg) pos15 0.035 vs exp004(nolseg) 0.089，**好 2.6 倍**；frame24 好 1.6 倍。
机制：LSeg 密集特征给球定位提供几何/时序一致性约束（不是逐像素精度）。

→ **保留 LSeg**。之前"nolseg 逐像素重建更好、弃 LSeg"的结论**被推翻**——接球要落点准，LSeg 换来的正是落点，这笔交易划算。

### 发现 6：反投影点接近球心，不是表面 → 无需半径补偿
球半径 **12 cm**，但 pos15 只有 3.5 cm(exp003) / 8.9 cm(exp004)，**远小于半径**。
说明渲染 depth 是 expected depth(加权中心)，反投影 median 点落在**球心附近**，不是表面壳。

→ **"表面差一个半径、需半径补偿"的假设被证伪、撤销。pos15 = 真实定位误差(depth 期望值误差 + 横向)。**

## 4. 训练实验横向结论

- **Exp003(LSeg)frame24 最好**(0.060)，但逐像素重建(depth/rgb)偏差；**nolseg(exp004/005)重建最好但 frame24 差** → frame24 与整体重建**脱钩**。
- **Exp002 11999→19999**：重建全面改善，frame24 反略退(0.089→0.092) → 再证脱钩。
- **batch2(exp005)**：frame24 略好(0.087 vs exp004 0.093) + acc 大幅稳(0.165 vs 0.388)，重建与 exp004 相当。

## 5. 策略结论

| 方向 | 结论 |
| --- | --- |
| **主攻** | **pos15(球定位精度)**，尤其 **p95 长尾**(接球最怕偶发崩) |
| **LSeg** | **保留**——它是当前压 pos15 的关键；可考虑把它当辅助 loss 加回 nolseg（训练扶手、推理不跑），拿"nolseg 重建 + LSeg 定位一致性" |
| 物理外推(A) | 搁置(外推不是瓶颈) |
| 改动 B(固化 a/j) | 搁置(a 不是瓶颈)；代码是消融开关，留着 |
| ball token | 价值不在选球，在**直接回归球心**、绕开 depth 反投影 → 终极方案 |
| 半径补偿 | **不做**(反投影已近球心) |

## 6. 待办 / 下一步

1. **pos15 误差的视线 / 横向分解**：看 pos15 误差是沿视线(=depth 期望值误差)还是横向(=定位)，决定修 depth 还是修横向。
2. **确认接球容差**：球半径 12cm，需知道接球允许多少偏差 → 决定盯 median 还是死磕 p95（exp003 median 3.5cm 可能已够，但 p95 16cm 会漏接）。
3. **p95 长尾归因**：哪些场景 frame24 崩 >12cm（选球崩 / depth 崩 / 球快离屏）。
4. **让 nolseg 拿到 LSeg 的一致性**：加回 LSeg 辅助 loss，或找别的几何一致性约束。
5. **ball token**：直接回归球心 + 物理外推，作为根治方案。
